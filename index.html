Latar Belakang Masalah

Diperlukan instrumen skrining mandiri berbasis web yang terstandar medis, cepat, dan mudah diakses dari perangkat manapun.

Arsitektur & Klasifikasi SVM

Sistem web full-stack mengadopsi kuesioner baku GAD-7 (Generalized Anxiety Disorder 7-item). Model Support Vector Machine (Linear Kernel, C=1.0) memprediksi tingkat kecemasan responden ke dalam kategori akurat, dilengkapi fitur unduh berkas resume diagnosis PDF untuk rujukan psikologis dan panel admin monitoring performa model.
